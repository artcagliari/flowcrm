# FlowCRM Frontend

React + Vite para consumir a API Laravel do FlowCRM.

## Stack

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Context API
- Framer Motion
- Recharts
- dnd-kit
- Lucide React

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Build

```bash
npm run build
```
